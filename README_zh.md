基于 Flask 和 Dash 构建的强大拖拽式 BI 平台。无需任何前端知识，即可创建精美的数据可视化报表。

## 功能特点

| 模块 | 功能 |
|------|------|
| **用户认证** | 注册、登录、会话管理，每个用户独立空间 |
| **数据源管理** | 支持 MySQL、PostgreSQL、Excel 文件上传，连接测试，密码加密 |
| **数据模型** | 从数据源选表、选字段，保存为虚拟数据集 |
| **仪表盘** | 拖拽式布局画布，图表大小位置自由调整 |
| **图表配置** | 选择数据模型 → 勾选维度和指标 → 选择图表类型 → 实时渲染 |
| **图表类型** | 柱状图、折线图、面积图、饼图、环形图、散点图、气泡图、直方图、箱线图、旭日图、3D 散点图、地理散点图等（20+ 种） |
| **布局保存** | 每个用户的仪表盘布局自动存入数据库，下次登录自动恢复 |

## 使用指南

### 1. 用户注册与登录
- 首次访问系统，点击"立即注册"创建账号
- 使用注册的邮箱和密码登录系统

### 2. 数据源管理
- 点击左侧菜单"数据源管理"
- 点击"添加数据源"按钮
- 选择数据源类型（MySQL/PostgreSQL/Excel）
- 填写连接信息或上传 Excel 文件
- 点击"保存"按钮完成添加

### 3. 数据模型创建
- 点击左侧菜单"数据模型管理"
- 点击"添加数据模型"按钮
- 选择数据源和表名
- 勾选需要的字段
- 点击"保存"按钮完成创建

### 4. 仪表盘设计
- 点击左侧菜单"仪表盘管理"
- 点击"创建仪表盘"按钮，输入名称
- 点击"编辑"按钮进入仪表盘编辑页面
- 点击右下角"+ 添加图表"按钮
- 选择图表类型、数据模型、维度和指标
- 拖拽图表调整位置和大小
- 系统会自动保存布局

### 5. 图表配置
- 在仪表盘编辑页面，点击图表的"编辑"按钮
- 修改图表名称、类型、数据模型、维度或指标
- 实时预览图表效果
- 点击"保存"按钮完成修改

## 技术栈

- **后端框架**：Flask
- **可视化框架**：Dash (Plotly)
- **数据库**：SQLite（开发环境）/ PostgreSQL（生产环境）
- **认证**：Flask-Login
- **ORM**：SQLAlchemy
- **文件上传**：Flask-Uploads
- **表单处理**：Flask-WTF
- **加密**：Passlib

---

## 注意事项

1. **安全提示**：生产环境请修改 `config.py` 中的 `SECRET_KEY`
2. **性能优化**：大数据量场景建议使用 PostgreSQL 数据库
3. **部署建议**：生产环境建议使用 Gunicorn + Nginx 部署
4. **扩展开发**：可以通过修改 `app/charts/forms.py` 添加更多图表类型
